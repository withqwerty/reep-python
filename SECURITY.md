# Security policy

## Supported versions

Security fixes go into the latest minor release. Before 1.0, only the latest release is
supported.

## Reporting a vulnerability

Report a vulnerability in the SDK or CLI code privately:

- through GitHub's [private vulnerability reporting](https://github.com/withqwerty/reep-python/security/advisories/new), or
- by email to getintouch@withqwerty.com with "reep-python security" in the subject.

Do not open a public issue for a vulnerability. Include the affected version, the steps
to reproduce the problem and its effect. We aim to reply within five working days.

## Scope

This policy covers the code in this repository. A wrong or harmful record in the Reep
Register data is a data correction; report it at <https://reep.football/submit>.
